# GitHub Profile Analyzer

A professional web application that analyzes GitHub user profiles, repositories, programming languages, and statistics using the GitHub API.

## Features
- Search any GitHub user profile
- View followers, following, and repositories
- Total stars and repository analysis
- Language statistics chart
- Top repositories section
- GitHub profile score
- Responsive and modern dashboard UI

## Tech Stack
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Chart.js
- GitHub REST API

```bash

cd github-profile-analyzer/backend
npm install
node server.js
```

Open `frontend/index.html` in your browser.
